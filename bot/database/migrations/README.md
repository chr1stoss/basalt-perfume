# SQL-миграции для существующих БД

Эти файлы нужны для ручного обновления схемы уже работающей базы. Бот не выполняет их автоматически при старте: `main.py` вызывает `init_db()` только для проверки подключения/схемы.

Перед запуском сделайте резервную копию, проверьте какие изменения уже применены и выполните только отсутствующий подходящий патч. Не импортируйте весь каталог подряд без проверки версии схемы. Для новой пустой БД вместо цепочки миграций используйте один из двух полных дампов в `../dumps/`: `14_full_install_empty_brands.sql` или `15_full_install_with_brands.sql`. Эти полные дампы удаляют таблицы приложения перед созданием схемы и не должны запускаться поверх production-БД.
