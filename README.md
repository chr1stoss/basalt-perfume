# Basalt Perfume Bot — PERFUME CENTER

## Назначение

Telegram-бот принимает Excel/CSV прайс-листы, обрабатывает строки, собирает каталог парфюмерии и обслуживает подписки, уведомления и пользовательские роли. WebApp поставляется отдельно двумя вариантами: HTML-оболочка (`index.html`) и PHP-оболочка (`index.php`). Не копируйте PHP WebApp в папку бота или `htdocs` бота.

## Основные каталоги

- `main.py` — точка запуска бота.
- `bot/` — обработчики, сервисы, БД и доменная логика.
- `bot/database/dumps/` — полные SQL-дампы для установки новой базы.
- `bot/database/migrations/` — ручные миграции существующей базы, если конкретный релиз их требует.
- `bot/database/seeds/` — демонстрационные данные для разработки.
- `bot/data/` — пользовательские файлы; при обновлении сохраняйте эту папку.
- `admin-cli.py` — CLI-инструменты для обслуживания и диагностики.
- `tests/` — автоматические тесты.
- `.env.example` — шаблон конфигурации без действующих секретов.

## Установка / обновление

1. Сделайте копию каталога бота, `.env`, `bot/data/` и MySQL базы.
2. Загрузите содержимое архива поверх исходного каталога бота. Не удаляйте действующий `.env` и пользовательские данные.
3. Проверьте значения `BOT_TOKEN`, `BOT_USERNAME`, `WEBAPP_URL`, `ADMIN_IDS` и `MYSQL_*`.
4. Для новой базы используйте один из `14_full_install_empty_brands.sql` / `15_full_install_with_brands.sql` через phpMyAdmin. Не импортируйте полный дамп поверх работающей БД.
5. Проверьте доступность MySQL и перезапустите бот способом, доступным на вашем хостинге.

## Переменные среды

`MYSQL_POOL_SIZE` ограничивает верхний предел соединений в пуле бота. Рекомендуемая отправная точка для одного процесса — `5`; учитывайте максимальное число соединений MySQL и количество процессов бота. `MYSQL_POOL_MINSIZE` задаёт минимум поддерживаемых соединений.

Секреты из `.env` нельзя коммитить в репозиторий или передавать в публичные отчёты. Пароль MySQL не следует передавать в аргументах командной строки; используйте `.env` или защищённое окружение.

## CLI — `admin-cli.py`

Запуск без параметров выводит справку. Команды:

```bash
python admin-cli.py --help
python admin-cli.py stats
python admin-cli.py users --role seller --limit 100
python admin-cli.py clean-cache
python admin-cli.py deletion-queue --limit 50
python admin-cli.py keys --limit 50
python admin-cli.py migrate-db --help
```

Миграция БД сначала выполняет плановую проверку без записи. Для переноса добавьте `--apply --confirm-target-db EXACT_DATABASE_NAME`. Перед записью проверьте исходную и целевую базу, снимите backup и остановите процессы, меняющие данные. Одноимённые таблицы назначения заменяются данными источника; таблицы, присутствующие только в назначении, автоматически не удаляются.

`clean-cache` очищает папки `__cache__` и `__pycache__` внутри дерева бота. Это безопасная служебная операция; она не очищает `bot/data/`.

## Как загружать прайс-листы

Отправьте Excel или CSV файл боту как документ. Обработка одного файла обычно занимает около 3–5 минут и зависит от размера прайс-листа. Если бот сообщает о конфликте с предыдущим файлом, проверьте действия в подтверждении; надёжнее всего заранее удалить старую конфликтующую версию в WebApp на странице «Прайс-листы».

## Профиль Telegram

Description и About на русском, английском и казахском языках подготовлены в `TELEGRAM_BOT_PROFILE_TEXTS.md` (в корне релизного архива и в папке бота, если файл поставляется рядом). Ограничения Telegram: Description — 512 символов, About — 120 символов. Установка выполняется через @BotFather.

## Проверка и диагностика

Локальная разработка:

```bash
python -m pip install -r requirements.txt
python -m pytest -q
```

Проверки в локальном окружении не гарантируют работоспособность production MySQL, Telegram API или хостинга. Реальную интеграцию проверяйте после загрузки и перезапуска.

## Советы по безопасности

- Telegram `initData` валидируется серверным API WebApp.
- Не переносите секреты MySQL или Telegram в клиентский JavaScript.
- Имена и исходники файлов, уже отправленные браузеру, нельзя надёжно зашифровать от DevTools. Минификация, отсутствие source maps и content-hash имена лишь затрудняют чтение.
