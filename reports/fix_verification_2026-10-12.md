# Basalt Perfume WebApp — исправления и проверка

Дата: 12.10.2026

## Что исправлено

- Кнопка «Прочитано» удаляет уведомление из Telegram, а запись уведомления остаётся в центре уведомлений WebApp.
- Очередь файлов ждёт тихое окно 2 секунды для отдельных загрузок и 3,8 секунды для media group; уведомление о принятии показывает число файлов в собранной группе. Обработка собранных файлов запускается через `asyncio.gather` с ограничением параллелизма парсера.
- В CSS добавлена общая система цветовых токенов: темы Mono/Ocean/Forest/Rose/Amber охватывают карточки, фон, панели, навигацию, поля, переключатели, иконки и модальные окна в светлом и тёмном вариантах.
- Орбы и их параметры создаются один раз и сохраняют движение при resize; цвет орбов следует активной теме.
- Аватар показывает инициалы сразу, изображение появляется после загрузки, ошибочное изображение убирается без broken-image glyph.
- Фильтры используют анимированные custom dropdown; drag handle модального окна остаётся закреплённым во время прокрутки.
- Прелоадер изменён на матрицу из 16 точек 4×4; стрелка «Все прайсы» выровнена с текстом; FAQ получил компактные отступы.
- Telegram-ссылки для бота, поддержки и продления доступа подключены; `/subscribe` и `?start=subscribe` открывают экран подписки, команда бота удаляется.
- Админ-строка занимает всю ширину карточки; API возвращает роль `user` или `admin`; SVG-иконкам заданы единые размеры и исправлена геометрия иконки настроек.
- Публичные сообщения об ошибках обработки не раскрывают типовые детали SQL/traceback; подробности остаются в серверном журнале.

## Что не проверялось в этой среде

Не запускались живой Telegram Bot API, production-БД и авторизованный Telegram WebApp в браузере. Поэтому реальное удаление сообщения, открытие deep links на конкретном Telegram-клиенте и объединение файлов в фактическом media group нужно один раз проверить после выкладки. Новых SQL-миграций для этих исправлений не добавлено; используемая таблица очереди `telegram_message_cleanup` должна уже существовать (для старой БД её создаёт `bot/database/migrations/04_telegram_notification_cleanup.sql`).

## Конфигурация

Полная сборка сохраняет присланные конфигурационные файлы, включая root `.env` и `htdocs/config/database.php`, чтобы не пришлось повторно вводить параметры. Не публикуйте эту сборку в открытом доступе; после проверки рекомендуется заменить токен бота и пароль БД, если архив передавался за пределы доверенного окружения.
