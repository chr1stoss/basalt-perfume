# UI and Telegram fixes — 2026-10-12

## Changes

- Extended the top bar's blurred background to the full viewport width.
- Removed transform-based animation from the app root and hover states that could leave text rendered softly in Telegram WebView.
- Restructured the filter sheet into a top drag handle, a separately scrolling content area, and a persistent action footer. The handle supports a quick downward flick to close the sheet; the close icon was removed.
- Re-rendered the settings screen when a language is selected so the chosen language previews across the whole screen before saving.
- Fixed the admin announcement textarea height and enabled internal scrolling instead of manual resizing.
- Reduced the admin users count badge height and removed the bright left hover stripe.
- Added a **Download** action for processed price lists. The button opens the bot with a `download_<file_id>` start payload; the bot verifies subscription, file ownership, file status and data-directory path before sending the document.
- Changed the review counter label to “Возможно N неточностей” (with English and Kazakh equivalents).
- Improved Telegram-link handling, including the `window.open` fallback used outside the Telegram WebApp.
- Bumped the CSS and JS cache versions in `htdocs/index.php`.
