# Тесты Telegram-бота

В этой папке находятся только тесты Python-бота `basalt-parfume-bot`: локализация сообщений и изображений, обработчики Telegram, загрузка и замена прайс-листов, парсер, очередь уведомлений, CLI и схема базы данных бота.

Тесты ограничены Python-ботом и его собственной схемой базы данных; проверки отдельного PHP/HTML-приложения не входят в этот набор.

Запуск из корня проекта бота:

```bash
python -m pytest tests
```

Для полного запуска установите зависимости проекта из `requirements.txt` и тестовую зависимость `pytest`. Часть тестов прайс-листов пропускается, если исходные Excel-файлы не переданы через `BASALT_TEST_PRICE_DIR`.
